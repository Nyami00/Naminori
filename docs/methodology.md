# 手法の体系化：波乗りあっき〜氏のアプローチ → ルールベース戦略

- 独占取材記事（投資の教科書「【手法解説】波乗りあっき〜さん独占取材」）の要点：
  - ポンド円（GBP/JPY）specialist、相場歴13年の専業トレーダー
  - 完全テクニカル分析（ファンダメンタルズはほぼ使わない）
  - 基本パターンは「N波動」「E計算値」「逆三尊」「ダブルボトム」

  - 「FX成功の秘訣は自分のお金の器を知ること」＝資金管理（ロットと日次pips目標のバランス）を最重視

要するに：**「波（トレンドの節）を構造で捉え、波の始まりに乗り、波が続く限り持ち、波が壊れたら降りる。賭け金は常に口座に対して一定の割合に制御する」** というトレンドフォロー型スイングである。

## 2. ルールへの翻訳

裁量要素（ラインの引き方、波の目視判定）を、日足で機械判定できる最小の代理ルールに置き換えた。**過剰適合を避けるため、いずれも古典的なパラメータ近傍のみを使う。**

| 裁量手法の要素 | 体系化ルール |
|---|---|
| N波動の上昇構造（高値・安値切り上げ） | 終値が過去N日の終値最高値を上抜け＝新しい波の開始（Donchian型ブレイクアウト、N=20） |
| 大きな流れの確認（チャネル方向） | 終値がEMA50より上（買い）／下（売り）のみエントリー |
| 直近スイング安値の下に損切り | 初期ストップ＝エントリー − 2.0×ATR(14)（スイング安値の統計的代理） |
| E計算値・波が伸びる限り利を伸ばす | シャンデリア型トレイリングストップ（最高終値 − 3.0×ATR(14)、切り上げのみ） |
| 波の崩壊で降りる／ドテン | 保有中に逆方向のNブレイクが出たら決済し反転（flip） |
| お金の器＝資金管理 | 1トレードのリスク＝口座残高の3%固定。数量 = 0.03×残高 ÷ ストップ幅 |
| 売り買い両方向 | ロング／ショート対称 |

## 3. 執行モデル（ルックアヘッド防止）

- シグナルは当日終値までのデータのみで計算し、当日終値で約定。
- ストップは翌日以降、当日の高値・安値に対して判定。ストップを飛び越える窓開けは「前日終値（＝寄り近似）」での不利約定。
- 当日算出のトレイリング水準は翌日から有効（同一バー内での更新→発動を禁止）。
- コスト：スプレッド往復 0.03円/GBP（GBPJPY実勢1〜3pipsの保守側）。

## 4. 過剰適合の防止

- パラメータは4種のみ（entry_lookback / trend_ema / stop_atr_mult / trail_atr_mult）。
- グリッドは各2値の計8組合せに限定（src/grid_search.py）。
- 選択はトレーニング窓（1〜4月）のみで行い、報告はテスト窓（5〜7月）の成績。隣接パラメータの成績崩壊チェック付き。
- 実データ入手後もこの手順以外のチューニングは行わない方針。

## 4.6 EMA 25/75/200 レビュー（2026-07-23 追補）

ユーザー情報「氏はEMA25・75・200も使用」を受け、FC2版ブログのアーカイブ（Wayback Machine上の fxyou1128.blog.fc2.com、2014年の記事群）で実際の使い方を確認し、データを2024-09-02まで遡って延長（488営業日、既存QC済み区間と完全一致）して実データで検証した。

**ブログ本文で確認した使い方（引用要旨）**
- EMA25＝短期の反応線・利確目標：「リカクは25EMAを目標にしてました」「ポンド円は25EMAで反転下落」
- EMA75＝波の背骨：「節目の高値・安値は75EMAを見て判断」「75EMAが形成してる角度＆形状を見る」「（トレンド）ラインは75EMAに沿って引く」、チャネル下辺との重なり＝高確率ポイント
- EMA200＝目線（レジーム）：「200EMAを上抜け失敗→下降の流れに変わったと認識し下目線」「1時間足の200EMAタッチは反発の可能性が高いポイント」
- 記事は主に15分〜4時間足のデイトレ文脈だが、役割分担は時間足非依存の枠組みとして記述されている。

**診断結果（評価期間2026-01-01〜07-22）**
- 全144日で 終値>EMA200 かつ パーフェクトオーダー（EMA25>75>200）。2026年前半は教科書的なEMA順行上昇であり、ロング限定の選択はEMA200/75トレンド判定の教義と完全に整合する。
- 採用戦略の3エントリーはいずれもEMA25の下（−0.3〜−1.6ATR）・EMA75近傍（+2.2／−0.5／−0.1ATR。特に6/18はEMA75にほぼ接地）・EMA200の大幅上方（+2.3〜+5.7ATR）で発生しており、**「EMA200上でのEMA25〜75ゾーンへの押し目買い」を水平線ベースで自動検出していた**ことが確認された。
- EMA75の支持線としての機能：2026年のEMA75タッチ26回中16回が上で引け、その後10日間の平均リターンは+0.95%。

**変種検証（ウォークフォワード規律は従来どおり）**
| 変種 | 訓練 | テスト | 通期 | 判断 |
|---|---|---|---|---|
| 採用構成（凍結） | +3.48 | +2.72 | +3.17 | 基準 |
| ＋EMA200ロングゲート | +3.48 | +2.72 | +3.17（トレード完全一致） | **採用**（後述） |
| ＋EMA75ロングゲート | +3.23 | +2.39 | +2.81 | 棄却（2/17の最良トレードを遮断） |
| EMA25押し目（EMA75上）| −1.22 | +0.96 | −0.39 | 棄却（タッチが頻繁すぎ選択性なし） |
| EMA75押し目（EMA200上）| +1.09 | +1.86 | +1.46 | 参考（機能するが採用構成に劣後） |

**結論**：EMA25/75/200層は採用戦略を「改善」はしないが「裏付け」る。EMA200ゲート（ロングは終値>EMA200のときのみ）は2026年結果を一切変えずに、ロング限定というアドホックな選択を「長期トレンド方向のみ取引する」という教義的条件に置き換えるため、params_final.json に正式採用した（swing_gate_ema: 200）。円高転換で価格がEMA200を割れば戦略は自動的に停止する。

## 4.7 10年検証（2026-07-23 追補：Dukascopy実スプレッド・複利ロット）

ユーザー要望（複利ロット確認＋過去10年のスプレッド込み検証）への対応。ロットはもともと「エントリー時残高の3%リスク」で複利連動（実証：リスク額30,000→31,853→36,110円と残高比例）。

- **データ**：Dukascopy datafeed の日足Bid/Ask（2014〜2026年、3,274営業日、bi5をLZMA+ビッグエンディアンでデコード）。2026年分は月次H1・日次M1ファイルから集計。stooqとの照合では終値差の中央値0.065〜0.088円（**日次区切りがUTC0時 vs NYクローズの規約差**であり整合）、日中極値は数銭単位で一致（2/17安値 207.229 vs 207.241）。
- **執行**：買いはAsk（終値+実測スプレッド）、決済はBid。ティック12日サンプル（Brexit・コロナ・介入日・平常日）で、執行時間帯（UTC0時）のティック実測スプレッドと課金額が通常日ほぼ一致・イベント日は過大課金の保守側であることを確認（results/gbpjpy_decade/tick_spread_check.csv）。
- **手順**：凍結パラメータ（params_final.json、spread_jpyのみ0に）を**一切再調整せず**2015-01-01〜2026-07-22に適用。土曜（フラットなプレースホルダ）と日曜（21〜24時UTCの薄いセッション、期間中623本）は除外——日曜3時間中のストップ発動は表現されない軽微な限定。取得スクリプトはコミット済みCSVをバイト一致で再生成できることを検証済み。
- **2026年の本編との差**：Dukascopy集計では2026年1〜7月は+21.9%（本編stooqベース+27.6%）。差の主因はスプレッドではなく日次区切りの規約差で、UTC0時区切りでは6月18日の3本目のシグナルが成立しない（監査レポートで定量確認）。

**結果**：シャープレシオ0.10（ブートストラップCI [−0.38, 0.58]、統計的にゼロと区別不能）、総リターン+5.8%（年率+0.5%）、最大DD 24.1%、33トレード・勝率36%・最悪R −1.0（3%リスク遵守）。年別では2015年−11.2%、2017年−6.1%と負け、2022年+8.8%・2025年+4.4%・2026年+21.9%に利益が集中。2016年（Brexit）・2019年はEMA200ゲートによりノートレード（下落年の回避に成功）。

**結論**：本戦略は円安上昇レジーム特化型であり、2026年の好成績（Dukascopyデータでも方向一致で再現）は普遍的なエッジではなくレジーム適合の産物。「常時稼働の収益戦略」としては不成立で、レジーム検出を前提とした限定運用のみが妥当。

## 4.8 改良探索：トレード数増×勝率向上の試み（2026-07-23 追補・否定的結果）

ユーザー要望「トレード回数を増やしつつ勝率を上げる」に対し、事前登録プロトコル（選択は訓練窓2015〜2021のみ、テスト窓2022〜2026.07は確認専用、選択基準=訓練シャープ最大かつ訓練トレード数40以上［第2ラウンドは30以上］かつ訓練勝率45%以上）で2ラウンド・計40構成を検証した（tools/run_improvement_search.py、results/improvement_search/）。

- 第1ラウンド（24構成）：方向（ロングのみ／ゲート付き両方向）×期間（10/20日）×ターゲット（境界/中間/2R）×タイムストップ（なし/15日）
- 第2ラウンド（16構成）：ブログの教えに基づくスプリング品質フィルタ（反発強度0.25ATR・下ヒゲ深さ上限）を追加

**結果：基準を満たす構成はゼロ。全40構成が訓練窓（2015〜2021年）でシャープレシオがマイナス（最良−0.04）。** 個別目標は達成可能（中間ターゲットで勝率50〜54%、期間10日でトレード数2倍超の69〜71件）だが、期待値が伴わない。ゲート付きショートは全構成で有害（GBPJPYの下落はV字的で、レンジ上限への戻りが止まらない）。

**結論：日足のスプリング/リジェクション系統には、円安レジーム外での正の期待値が存在しない。** トレード数・勝率の目標は「レジーム限定運用の枠内」でのみ意味を持つ。これ以上この系統を深掘りすることは多重比較による偽発見リスクを増やすだけであり、探索を打ち切った。別のエッジ源（本人が実際に使う15分足等の日中足、通貨ペア間シンクロ、ボラティリティレジーム）は別の研究プログラムとして計画すべきである。

## 4.9 新エッジ源の探索：H1仮説×2＋クロス銘柄転写（2026-07-23 追補）

**H1プログラム（否定的結果）**：Dukascopy H1 Bid/Ask 76,528本（2014〜2026）で、ブログ由来の2仮説を事前登録検証（各12構成、選択は訓練窓2015〜2021のみ、基準=訓練n≥100・勝率≥45%・シャープ最大）。仮説A「H1 200EMAタッチ反発」（本人明言の高確率ポイント）と仮説B「前日高安ラインへのH1スプリング」は、いずれも基準を満たす構成に正の訓練シャープがなく、**24構成すべてでテスト窓（2022以降）シャープがマイナス**。重要な構造発見：平均回帰系はレンジ期（2015〜21）に微プラス・トレンド期（2022以降）に全滅で、日足トレンド系と正確に鏡像。「どのスタイルが効くかはレジームが決める」。仮説C（ペアシンクロ）はA/Bに勝者がないため打ち切り。見えた結果からレジームスイッチを後付け構築することは in-sample の物語化になるため実施しない。

**クロス銘柄転写（肯定的結果）**：凍結GBPJPYパラメータを未使用データのEURJPY/USDJPY日足Bid/Askへ無変更適用。EURJPY：通期シャープ+0.32・+30.7%（2022以降+0.77、2026年+12.3%）。USDJPY：+0.13・+9.1%（2026年+8.4%）。**3ペアとも「クロスの上昇レジームで勝ち、それ以外は横ばい」という同一プロファイルを再現**し、コンセプトがGBPJPY固有の偶然でないことを示した。勝ち年はペア間でずれる（2017=EURJPY、2021=USDJPY、2026=全部）。

**等ウェイト3ペアポートフォリオ（追加パラメータゼロ）**：同一凍結ルールを3ペアに1/3資金ずつ（各スリーブ内3%リスク複利）。結果：通期シャープ**+0.28**・+17.2%・**最大DD 10.2%**（単体ペアの24〜27%から半減）、2022以降**+0.91**・+23.9%、トレード数92件/10年（GBPJPY単体の約3倍）。複数ペア運用は本人の実践（ポン円・ドル円・ユロ円）と一致し、フィットしたパラメータはない。注記：ポートフォリオ化の判断自体は単体結果を見た後だが、同一ルールの複数銘柄適用は事前に標準的な設計であり、転写テスト自体はクリーンなアウトオブサンプルである。

## 5. 評価指標

- シャープレシオ：日次リターン（時価評価済みエクイティ）から `mean/std × √252`、無リスク金利は0と仮定。
- 補助：Sortino、最大ドローダウン、勝率、平均R倍数。
- 統計検証（src/validate.py、独立エージェントが実行）：
  - 移動ブロック・ブートストラップによるシャープレシオ分布（モンテカルロ）
  - Newey-West修正t検定（日次平均リターン）
  - トレードR倍数の符号反転ランダム化検定
  - トレード順序シャッフルによるドローダウン分布
  - 3%リスク仕様の実証チェック（最悪R倍数が−1R近傍か）

## 6. 既知の制約

- 日足のH/L/C近似（始値=前日終値）。日中足の裁量ニュアンス（ラインタッチの精度）は再現しない。
- 週末ギャップ・指標発表時のスリッページは、窓開け時の不利約定ルール以上にはモデル化していない。
- スワップ（金利差損益）は未計上。GBP/JPYロングは2026年時点でプラススワップ傾向のため保守側の省略。

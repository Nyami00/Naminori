# 手法の体系化：波乗りあっき〜氏のアプローチ → ルールベース戦略

## 1. 参照元と手法の骨子

参考指定されたブログ「ポンド円 波乗り日記」（波乗りあっき〜氏、https://ameblo.jp/fxyou1128/ ）は、本サンドボックスのネットワークポリシーで直接閲覧できなかったため（CONNECT 403 / Host not in allowlist）、Web検索のダイジェスト経由で以下の一次・二次情報を収集した。

- ブログ本体のテーマ構成：「相場の流れを見る」「トレンドライン」「チャンネルライン」「あっき〜FX講座」「トレード結果」「手法解説」（記事 entry-12602642417 ほか）
- 独占取材記事（投資の教科書「【手法解説】波乗りあっき〜さん独占取材」）の要点：
  - ポンド円（GBP/JPY）specialist、相場歴13年の専業トレーダー
  - 完全テクニカル分析（ファンダメンタルズはほぼ使わない）
  - 基本パターンは「N波動」「E計算値」「逆三尊」「ダブルボトム」
  - フィボナッチチャネル、トレンドライン／チャネルラインで波の流れを読む
  - 「FX成功の秘訣は自分のお金の器を知ること」＝資金管理（ロットと日次pips目標のバランス）を最重視

要するに：**「波（トレンドの節）を構造で捉え、波の始まりに乗り、波が続く限り持ち、波が壊れたら降りる。賭け金は常に口座に対して一定の割合に制御する」** というトレンドフォロー型スイングである。

## 2. ルールへの翻訳

裁量要素（ラインの引き方、波の目視判定）を、日足で機械判定できる最小の代理ルールに置き換えた。**過剰適合を避けるため、いずれも古典的なパラメータ近傍のみを使う。**

| 裁量手法の要素 | 体系化ルール |
|---|---|
| N波動の上昇構造（高値・安値切り上げ） | 終値が過去N日の終値最高値を上抜け＝新しい波の開始（Donchian型ブレイクアウト、N=20） |
| 大きな流れの確認（チャネル方向） | 終値がEMA50より上（買い）／下（売り）のみエントリー |
| 直近スイング安値の下に損切り | 初期ストップ＝エントリー − 2.0×ATR(14)（スイング安値の統計的代理） |
| E計算値・波が伸びる限り利を伸ばす | シャンデリア型トレイリングストップ（最高終値 − 3.0×ATR(14)、切り上げのみ） |
| 波の崩壊で降りる／ドテン | 保有中に逆方向のNブレイクが出たら決済し反転（flip） |
| お金の器＝資金管理 | 1トレードのリスク＝口座残高の3%固定。数量 = 0.03×残高 ÷ ストップ幅 |
| 売り買い両方向 | ロング／ショート対称 |

## 3. 執行モデル（ルックアヘッド防止）

- シグナルは当日終値までのデータのみで計算し、当日終値で約定。
- ストップは翌日以降、当日の高値・安値に対して判定。ストップを飛び越える窓開けは「前日終値（＝寄り近似）」での不利約定。
- 当日算出のトレイリング水準は翌日から有効（同一バー内での更新→発動を禁止）。
- コスト：スプレッド往復 0.03円/GBP（GBPJPY実勢1〜3pipsの保守側）。

## 4. 過剰適合の防止

- パラメータは4種のみ（entry_lookback / trend_ema / stop_atr_mult / trail_atr_mult）。
- グリッドは各2値の計8組合せに限定（src/grid_search.py）。
- 選択はトレーニング窓（1〜4月）のみで行い、報告はテスト窓（5〜7月）の成績。隣接パラメータの成績崩壊チェック付き。
- 実データ入手後もこの手順以外のチューニングは行わない方針。

## 5. 評価指標

- シャープレシオ：日次リターン（時価評価済みエクイティ）から `mean/std × √252`、無リスク金利は0と仮定。
- 補助：Sortino、最大ドローダウン、勝率、平均R倍数。
- 統計検証（src/validate.py、独立エージェントが実行）：
  - 移動ブロック・ブートストラップによるシャープレシオ分布（モンテカルロ）
  - Newey-West修正t検定（日次平均リターン）
  - トレードR倍数の符号反転ランダム化検定
  - トレード順序シャッフルによるドローダウン分布
  - 3%リスク仕様の実証チェック（最悪R倍数が−1R近傍か）

## 6. 既知の制約

- 日足のH/L/C近似（始値=前日終値）。日中足の裁量ニュアンス（ラインタッチの精度）は再現しない。
- 週末ギャップ・指標発表時のスリッページは、窓開け時の不利約定ルール以上にはモデル化していない。
- スワップ（金利差損益）は未計上。GBP/JPYロングは2026年時点でプラススワップ傾向のため保守側の省略。

## 最終戦略（params_final.json）

2026年のGBP/JPYは安値を切り上げ続ける上昇チャネル（N波動）だった。ブレイクアウト追随型は全構成がマイナス（訓練窓シャープ−1.95〜−2.79）で棄却し、ブログ手法の核心である「ラインでの反発を取って波に乗る」形を採用した。

- **セットアップ（スプリング＝ダブルボトムの2点目）**: 日中に過去20日安値ラインを下抜け、終値で上に戻して引けた日＝「下抜けがダマシと確認された支持線反発」
- **エントリー**: その日の終値で買い（**ロングのみ・終値>EMA200のときに限る**。EMA200ゲートは2026年の結果を一切変えずにレジーム転換時の自動停止を与える教義的条件。詳細は docs/methodology.md 4.6節のEMA25/75/200レビュー）
- **損切り**: 反発ヒゲの安値 − 0.5×ATR(14)（直近安値のすぐ下）。**1トレードのリスクは口座残高の3%固定**（数量=リスク額÷ストップ幅）
- **利確（N/E計算値の構造ターゲット）**: 過去20日高値ライン（レンジ反対側）到達で決済
- **コスト**: スプレッド往復3pips計上。執行は終値、ストップ/ターゲットは翌日以降の高安値で判定（ルックアヘッドなし、同日両達成時はストップ優先の悲観処理）

## 実行方法

```bash
# 0) データ再取得（stooq.comが許可リストにある場合）
python3 tools/fetch_stooq_gbpjpy.py

# 1) エンジンの単体テスト
python3 tests/test_strategy.py

# 2) データQC（独立ソースの実測アンカー22点と照合）
python3 src/data_qc.py --data data/gbpjpy_daily_2026.csv

# 3) ウォークフォワード探索（1-4月で選択、5-7月で検証）
python3 src/grid_search.py --data data/gbpjpy_daily_2026.csv \
    --train-end 2026-04-30 --eval-start 2026-01-01 --mode swing

# 4) 本番バックテスト（凍結済み最終パラメータ）
python3 src/backtest.py --data data/gbpjpy_daily_2026.csv \
    --params params_final.json --out results/gbpjpy_final --eval-start 2026-01-01

# 5) 統計検証（モンテカルロ＋有意性検定）
python3 src/validate.py --results results/gbpjpy_final \
    --sharpe-target 1.5 --risk-per-trade 0.03 --n-boot 10000
```

## データについて

`data/gbpjpy_daily_2026.csv` は stooq.com のヒストリカルページから取得した実データ（209営業日、2025-10-01〜2026-07-22）。当初このサンドボックスは全ての市場データ源を遮断しており、ユーザーが stooq.com を許可リストに追加したことで取得可能になった（経緯の記録: docs/data_blocker.md、取得スクリプト: tools/fetch_stooq_gbpjpy.py）。データ品質は、別経路（exchange-rates.org系・wise.com）で収集した実測アンカー22点との包含関係チェックで検証済み（src/data_qc.py が PASS）。
